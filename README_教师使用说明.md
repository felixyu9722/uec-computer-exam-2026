## 🌟 核心功能与教师使用特色

1. **三维教学模式自由切换**：
   - 🎓 **教师全解模式**（默认）：完整呈现官方标准答案、董总高一/高二课本对应章节、命题思路、深层逻辑剖析，以及详尽的干扰选项排除分析。
   - ✍️ **自测练习模式**：提供给学生或课堂测验，点击选项即时判定对错、实时统计答题卡状态。
   - 📄 **卷面纯享模式**：隐藏所有答案与解析标识，还原本真考卷版面，适合投影讲解或模拟统考出题。
2. **快速题号秒级定位**：
   - 右侧常驻题号抽屉（选择题 1~40 题网格、作答题 Q1~Q6 快速导览），点击即平滑滚动对齐。
   - 支援关键词即时搜索（如“网络”、“CPU”、“流程图”、“PAPA”等）。
3. **独创交互式演练组件**：
   - **试卷二 第1题 (d) 小题**：网络传输耗时推算器（可自订输入文件容量与网速，直观呈现 $1\text{ Byte} = 8\text{ bits}$ 的二进制与十进制换算对比）。
   - **试卷二 第4题 (a) 小题**：地铁票价计算算法 SVG 动态流程图与单步追踪模拟器（输入乘坐站点数，实时点亮判断条件与处理框的执行路径，直观展示多阶梯分支结构）。
4. **一键列印 / 导出 PDF 讲义**：
   - 网页专门深度优化了 `@media print` 样式，在浏览器中按下 `Ctrl + P` 或点击页面右上角的「列印 / 导出PDF」，即可自动去除多余侧边栏，生成格式紧凑排版规整的高清教研讲义。

### 试卷二：作答题 (6大题，60%)
- **第 1 题（10%）· 智慧办公与网络计算**：指纹生物识别（防代打卡）、RFID门禁控制、复合型触控萤幕与大屏幕投影、500,000KB @ 512Mbps 上传时间推算（推导得 8 秒）。
- **第 2 题（10%）· 电脑室系统升级评估**：作业系统核心功能、Windows 11 硬体门槛 (TPM 2.0 / 64位CPU) 与软体相容性评估、淘汰旧机与安装轻量 Linux、盗版安全漏洞与《版权法令》风险、系统重灌前数据备份。
- **第 3 题（10%）· 局域网架构与网络边界防护**：主从式集中管理与对等式去中心化优缺点对比、异构网络跨协定互联选用**闸道器 (Gateway)** 的充要理由、防火墙封包过滤与 NAT 防护机制。
- **第 4 题（10%）· 地铁票价计费演算法**：绘制规范四阶梯条件判断流程图 ($N \le 5$, $N \le 10$, $N \le 15$)、判定为选择结构、动用变数储存用户动态输入站点。
- **第 5 题（10%）· 邮件病毒防范与应急处置**：附件防毒扫瞄手段、电脑病毒五大特征（传染性、隐蔽性、潜伏性、破坏性、可触发性）、重要危害、中招后**第一时间物理拔网线断网**及后续处置。
- **第 6 题（10%）· 网络舆论风波与法律伦理**：PAPA 资讯准确性 (Accuracy) 责任剖析、网络霸凌人身攻击之批判、事前事实核查机制、《1997年电脑犯罪法令》（未入侵系统故未触犯）与《1998年通讯及多媒体法令》（散布虚假不实资讯涉嫌触犯）法条辨析。
